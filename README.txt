# ملوك النت في مصر — النسخة الأونلاين V1

هذه النسخة تنقل الطلبات من `localStorage` إلى قاعدة بيانات على الخادم (`data.json`).

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح المجلد وشغّل:
   `node server.js`
3. افتح:
   `http://localhost:3000/`

## لوحة الإدارة
- الرابط: `/admin.html`
- المستخدم الافتراضي: `admin`
- كلمة المرور الافتراضية: `1234`

للاستخدام الحقيقي غيّر بيانات الإدارة عبر متغيرات البيئة:
- `ADMIN_USER`
- `ADMIN_PASS`

## ملاحظة مهمة
هذه خطوة انتقالية عملية: قاعدة البيانات الآن على الخادم في ملف `data.json`.
قبل التشغيل التجاري الفعلي يُفضّل نقلها إلى PostgreSQL/MySQL أو خدمة قاعدة بيانات مُدارة، وإضافة HTTPS، وحماية أقوى لتسجيل الدخول، ومحددات لمكافحة الطلبات الآلية.


## الرفع على الإنترنت — Render

أسهل مسار للنسخة التجريبية:
1. ارفع مجلد المشروع إلى GitHub كمستودع خاص.
2. افتح Render واختر New > Web Service.
3. اربط مستودع GitHub.
4. اختر المشروع.
5. Build Command: `npm install`
6. Start Command: `npm start`
7. أضف متغيرات البيئة:
   - ADMIN_USER = اسم مستخدم الإدارة
   - ADMIN_PASS = كلمة مرور قوية
8. اضغط Deploy.

ملاحظة: النسخة الحالية تستخدم `data.json` كقاعدة بيانات انتقالية. على Render نظام الملفات للخدمات المجانية مؤقت، لذلك لا نعتمد عليها لتشغيل تجاري حقيقي. بعد نجاح التجربة ننتقل إلى PostgreSQL حتى تبقى الطلبات محفوظة بشكل دائم.
